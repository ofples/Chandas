# Timer setup and running guide

## Start with a working timer

A new installation opens an unsaved working timer directly. Tap its name to edit it in place. Until you choose a custom name, the name follows the main interval. A single interval shares the configuration name and has no separate step-name field.

Use the familiar duration presets and sound row. The horizontal control row opens focused controls for run length, clock alignment, the full volume mixer, cue vibration and alarm options. Optional editors use smaller centered overlays, with the parent visible behind them. Their summaries show the configured values after you move to another control. Volume rows use quiet labels and a right-side play button to audition at the current master/channel level; repeated previews cycle through multiple selected sounds without changing timer playback. Closing the volume view stops its preview. The interval alarm panel contains only its toggle; alarm sound and duration remain in Settings. Default vibration profiles, alarm defaults, schedules, appearance, Focus and system integrations are in the three-dot Settings menu.

## Add steps and sub-bells

**Add step** turns the main body into compact cards. Whole-timer controls sit above the sequence and Add step follows the last card. Drag a card's dotted handle to move it immediately; scroll using the rest of the card. The surrounding cards animate into place while dragging; the new order commits on release without waiting for an animation. Tap a card to edit its name, duration, sound, volume, vibration or end alarm in a sheet, using the same interval editor as the one-step page. Its editable name is the heading. Swipe a step or bell left to request deletion, or right to duplicate it immediately. A swipe needs a clear horizontal movement of roughly one third of the card (80–120px); a short flick, cancelled gesture or vertical scroll does not act. Deletion asks for confirmation immediately on release. The colored action background fills the exposed area and resets independently of the action. The three-dot menus retain accessible duplicate/delete alternatives. Run length and clock alignment apply to the whole ordered round.

The whole sub-bell summary card opens the sub-bell list; only its toggle changes enablement. Tap a bell to edit its name inline, sound and cadence. **Repeat** controls the fixed cadence without erasing selected offsets. Random gaps, after-start and before-end cues can be combined. The action row sits below the editable bell title. Random, After and Before toggle on/off in the action row; enabled summaries reopen their control without changing enablement. Color, cue selection, vibration and watch-face visibility open smaller centered controls. Cue selection has no duplicate explanatory paragraph; its button is highlighted only while the control is open. Bell volume stays visible. Duplicate/delete commands live in the three-dot menu. Shortening an interval retains dormant points. A fully selected repeating cadence follows cadence changes and adds the new occurrences when its interval grows; customized selections and dormant points remain intact.

Tap the top handle or a plain sheet title to toggle full/partial height, or drag the handle. Focused controls fit their content where possible and retain their expanded mode when content changes. Tap its backdrop or drag down from the partial view to dismiss the top layer. Android Back, Escape and accessibility handle actions provide alternatives. Sound choices open in a shorter sheet above the cue editor. Tap outside or drag down to return one layer, including from a Settings section. There are no generic Back, Done, Cancel, Expand or Collapse navigation buttons; cancellation of a confirmation remains an explicit choice. Web scrollbars are hidden without disabling scrolling, and Settings remembers its menu position when returning from a section. Selections are applied to the working draft as you edit; explicit save, import and confirmation actions remain where needed.

## Save and switch configurations

For a bounded run, **Add completion sound** appears beside **Add step**. Its cue and removal options stay here, separate from alarm defaults.

Open the gallery configuration icon to manage timers. The current working timer is at the top, with its visualizer and Working copy/Unsaved changes/Saved status. **Save** on this card immediately creates a saved configuration with the current name, or updates the selected one. There is no separate naming modal and no Save button on the main timer page. A clean saved card has Save disabled. Edit the name from the current card or main page.

**Save a copy** creates and selects a uniquely named copy immediately, retaining the outgoing draft. It is available in the current-card and library menus. Availability while running is a checked item in each card's menu; it does not occupy the card body. Other card actions include rename, duplicate, export and delete. Import and return/new working timer are in the library heading menu.

Configuration cards show every step's duration and sub-bell timeline. Each saved configuration keeps a saved snapshot and a separate durable draft. Dirty switching offers Save, Keep draft or Discard; tapping outside cancels the switch. Saving an unnamed timer during switching also uses its current name immediately. Failed saves retain the draft and do not replace the saved snapshot. Library actions do not discard another configuration's edits. The unsaved working timer remains independently available.

## Running and recovery

Starting uses a frozen snapshot. Setup drafts and library actions do not replace the accepted run. Existing running watchface and immediate controls remain; previous/next skip steps silently and pause/resume retain timing and sound position.

Existing saved records remain intact. Legacy work copies, presets, settings and sounds retain their migration/recovery paths. A legacy flat timer with no library becomes a working copy rather than an invented saved card. Unreadable/future records are preserved for recovery. The retired experiment's key is not read or promoted.

# Timer setup and running guide

## Start with a working timer

A new installation opens an unsaved working timer directly. Tap its name to edit it in place. Until you choose a custom name, the name follows the main interval. A single interval shares the configuration name and has no separate step-name field.

Use the familiar duration presets and sound row. The horizontal control row opens run length, clock alignment, volume, cue vibration and alarm options. Their summaries show the configured values after you move to another control. Default vibration profiles, alarm defaults, schedules, appearance, Focus and system integrations are in the three-dot Settings menu.

## Add steps and sub-bells

**Add step** turns the main body into compact cards. Hold a card's dotted handle to drag it into a new position. Tap a card to edit its name, duration, sound, volume, vibration or end alarm in a sheet. Run length and clock alignment apply to the whole ordered round.

The sub-bell summary and timeline open a sub-bell list. Tap a bell to edit its name inline, sound and cadence. **Repeat** controls the fixed cadence without erasing selected offsets. Random gaps, after-start and before-end cues can be combined. Their buttons open focused editors; color, volume, offsets, vibration and watch-face visibility are in the horizontal property row. Shortening an interval retains dormant points. A fully selected cadence follows cadence changes; customized selections retain compatible points.

Drag the handle to expand or reduce a sheet. Tap its backdrop or drag down from the partial view to dismiss the top layer. Android Back, Escape and accessibility handle actions provide alternatives. There are no generic Done, Expand or Collapse toolbar buttons. Selections are applied to the working draft as you edit; explicit save, import and confirmation actions remain where needed.

## Save and switch configurations

**Save** creates a saved configuration for an unsaved timer, or updates the currently selected saved configuration. Open **Settings → Configurations** to switch, use **Save as…** for the current draft, rename, duplicate, delete, import/export or change running-selector visibility.

Each saved configuration keeps a saved snapshot and a separate durable draft. Dirty switching offers Save, Keep draft, Discard or Cancel. Save as selects the new card and preserves the outgoing draft. Library actions do not discard another configuration's edits. The unsaved working timer is retained independently and can be reopened from the library.

## Running and recovery

Starting uses a frozen snapshot. Setup drafts and library actions do not replace the accepted run. Existing running watchface and immediate controls remain; previous/next skip steps silently and pause/resume retain timing and sound position.

Existing saved records remain intact. Legacy work copies, presets, settings and sounds retain their migration/recovery paths. A legacy flat timer with no library becomes a working copy rather than an invented saved card. Unreadable/future records are preserved for recovery. The retired experiment's key is not read or promoted.

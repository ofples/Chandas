## Prototype decisions retained in production

The setup experiment is retired. The following interaction patterns are implemented in the production editor and runtime, through production providers and components:

| Prototype reference | Production mapping |
|---|---|
| Unified setup flow and capability rail | `src/screens/UnifiedTimerConfigScreen.tsx` with labelled horizontal actions and persisted enabled capabilities. |

| Start and previews | Setup previews use the unified timeline; Start follows the production App and `useTimerV2` path after native capability negotiation. |
| Draft transitions and validation | Production tests cover config transitions, migration/recovery, timeline and session behavior; the experimental model and tests have been deleted. |

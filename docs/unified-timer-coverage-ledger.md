Legend: **Current** summarizes implemented behavior in the existing app; **Destination** is the unified contract target; **Evidence required** is the acceptance check. `Parent review` means details need confirmation during the architecture review.

|---|---|
| `TimerSetupPrototype.tsx` setup flow and capability rail | Refactor/replace `TimerV2ConfigScreen.tsx` in place after model/runtime support; preserve horizontal labelled action chips and keep each enabled capability's fields visible simultaneously. |

Prototype keys never participate. |

| Prototype subbell editor | Production `SubBellFlowSheet`, `TrackEditorContent`, `OffsetGrid`, `ColorSelector`, sound selection; make step-scoped and extend pure timeline/normalizer. |
| Prototype shared sound picker | Reuse `SoundPickerSheet`, sound import normalization/preview; shared store across all saved cards/drafts. |
